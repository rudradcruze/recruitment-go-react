# The app does not verify the email address of a Candidate

A Candidate gives a name and an email address on the Exam link. The app does not check that the Candidate owns the address. The app allows one Attempt for each email address for each Exam. A Candidate with an open Attempt can enter the same address to resume it.

This stops an honest Candidate from a second try by mistake. It does not stop a person who enters a different address. It also lets anyone who knows the Exam link and an address resume the open Attempt of that address. We did not add a verification step, because it needs an email service and makes each Candidate wait. If a result must be certain, use one link for each invited Candidate. The Exam link design must then change.
